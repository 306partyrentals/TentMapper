TentMapper Ground Textures — Batch 1

Upload these files directly into:
Tentmapperassets/

Recommended GitHub Pages base URL:
https://306partyrentals.github.io/TentMapper/Tentmapperassets/

Included ground materials:
- Fresh Grass
- Dry Grass
- Crushed Gravel
- Concrete
- Asphalt

File naming pattern:
- tentmapper-ground-[name]-tile-1024x1024.webp  = main seamless ground texture
- tentmapper-ground-[name]-thumb-300x160.webp   = flipbook thumbnail

Notes:
- The tile files are square ground textures for repeating on the 3D ground plane.
- The thumb files are lightweight flipbook previews.
- Keep the filenames exactly as-is when uploading to GitHub so the code references work cleanly.
